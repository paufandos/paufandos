## What I build outside work

### fandOS

My private app for managing and organising my day on iPhone, iPad and Mac, built with SDD, my own agent-kit and different AI providers. The app syncs with my own API on Cloudflare Workers and D1. Claude Code uses tools on an MCP server connected to that API to query and update my schedule, my weekly menu or my workouts. [My website shows the app with sample data](https://paufandos.com/en/#projects).

Swift · SwiftUI · TypeScript · Cloudflare Workers · D1 · MCP

### agent-kit

A set of rules, tools and instructions for AI agents that I use every day to develop. It came from the need to coordinate different AI providers so they work together under my own rules and style. Claude Code coordinates and hands out the tasks and Codex reviews every change.

It includes a JavaScript command-line tool for Node.js: `ak usage` shows how much of each provider's usage allowance is left and `ak report` logs tool failures. The code is private.

JavaScript · Node.js · Claude Code · Codex

### [Adivina la palabra](https://github.com/paufandos/AdivinaLaPalabra)

My final Higher Diploma in Web Application Development (DAW) project, completed during my internship at Sopra Steria from March to June 2023. It's a Wordle-style game in Spanish: the backend picks the secret word, checks guesses and returns the hints.

Java · Spring Boot · Hibernate · MySQL · Angular
