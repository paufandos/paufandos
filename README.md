## What I build outside work

### fandOS

My app for planning the day on iPhone, iPad and Mac. It works offline and syncs with my API on Cloudflare Workers and D1. An AI assistant can query and modify its data through the app's MCP server. The code is private; [my website shows the app with sample data](https://paufandos.com/en/#projects).

Swift · SwiftUI · TypeScript · Cloudflare Workers · D1 · MCP

### agent-kit

I built agent-kit because I work with Claude Code and Codex at the same time. It's a JavaScript command-line tool for Node.js that installs the rules and skills for both.

`ak usage` shows how much of each one's usage allowance is left and `ak report` logs tool failures. The code is private.

JavaScript · Node.js · Claude Code · Codex

### [Adivina la palabra](https://github.com/paufandos/AdivinaLaPalabra)

My final Higher Diploma in Web Application Development (DAW) project, completed during my internship at Sopra Steria from March to June 2023. It's a Wordle-style game in Spanish: the backend picks the secret word, checks guesses and returns the hints.

Java · Spring Boot · Hibernate · MySQL · Angular
